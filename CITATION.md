# Citing AIMAC

If you use AIMAC in your research, please cite it as follows:

## BibTeX

```bibtex
@software{aimac2025,
  author = {GAAD Foundation},
  title = {AIMAC: AI Model Accessibility Checker},
  year = {2025},
  url = {https://github.com/GAAD-Foundation/AIMAC},
  version = {1.0.0}
}
```

## APA Style

GAAD Foundation. (2025). *AIMAC: AI Model Accessibility Checker* (Version 1.0.0) [Computer software]. https://github.com/GAAD-Foundation/AIMAC

## Chicago Style

GAAD Foundation. "AIMAC: AI Model Accessibility Checker." Version 1.0.0. 2025. https://github.com/GAAD-Foundation/AIMAC.

## About the Project

AIMAC benchmarks Large Language Models (LLMs) on their ability to generate accessible HTML. It uses [axe-core](https://github.com/dequelabs/axe-core), the industry-standard automated accessibility testing engine.
